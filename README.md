# Roulette Replay

구슬 룰렛을 돌린 뒤 **그 결과가 나온 과정까지 다른 사람과 동일하게 확인할 수 있도록** 만든 버전입니다.

기존 룰렛은 링크를 공유해도 각자 다시 랜덤으로 실행되기 때문에 결과가 달라질 수 있습니다. 이 프로젝트는 룰렛에 사용된 참가자, 설정, 난수 seed와 실행 시각을 URL에 함께 저장하여 공유받은 사람도 같은 조건의 라운드를 다시 볼 수 있도록 수정했습니다.

공유 링크에는 **결과 URL을 만든 날짜와 시간(KST)** 이 기록되며, 화면 상단에도 `실행 결과 · YYYY. MM. DD. HH:mm:ss KST` 형태로 표시됩니다. 링크는 생성 시점부터 **1시간 동안만 유효**하며 이후에는 만료 처리됩니다.

## 사용법

1. 참가자와 룰렛 옵션을 설정하고 실행합니다.
2. `🔗 결과 URL` 버튼을 누릅니다.
3. 생성된 URL을 다른 사람에게 전달합니다.
4. 링크를 받은 사람은 기록된 실행 시각과 함께 같은 seed/설정의 룰렛을 확인할 수 있습니다.
5. 링크는 생성 후 1시간이 지나면 만료됩니다.

## 구현 방식

URL에는 `seed`, 참가자 목록, 맵, 스킬 여부, 당첨 방식과 함께 URL 생성 시각인 `at` 값이 저장됩니다. 난수는 seeded PRNG를 사용해 같은 입력에서 같은 난수 흐름을 사용하도록 했습니다.

단, 이 방식은 영상이나 프레임을 서버에 저장하는 방식이 아니라 동일한 입력과 난수열로 물리 시뮬레이션을 다시 실행하는 방식입니다. 따라서 서로 다른 브라우저/CPU/WASM 환경까지 포함한 장기적인 비트 단위 동일성까지 보장하는 녹화 재생 방식은 아닙니다.

별도 서버나 DB 없이 GitHub Pages에서 동작하도록 구성했습니다.
